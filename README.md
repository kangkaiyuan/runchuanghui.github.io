# 润创汇 (Runchuanghui)

高质量项目与专业资本匹配平台

## 项目简介

润创汇是一个连接高质量创业项目与专业投资机构的双边匹配平台，通过严格筛选机制和智能匹配算法，为创业者和投资者提供精准、高效的项目资本对接服务。

## 核心功能

### 项目方服务
- 投资机构智能匹配
- 商业计划书优化指导
- 路演技巧培训
- 全程对接协调

### 投资方服务
- 高质量项目筛选
- 行业趋势分析报告
- 创始人背景调查
- 尽职调查支持

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **样式**: 自定义CSS，响应式设计
- **图标**: Font Awesome 6.4.0
- **字体**: Inter (Google Fonts)
- **部署**: GitHub Pages
- **域名**: runchuanghui.xyz

## 设计理念

### 品牌色彩
- **主蓝色** (#1a56db): 代表专业、信任、水元素（五行补水）
- **主绿色** (#10b981): 代表成长、发展、木元素（五行补木）
- **强调橙** (#f59e0b): 代表连接、行动、活力

### Logo设计
水滴生长型Logo，象征资本（水）滋养创业（木），体现"润创"理念。
